📝 불량 등록 방법
  1. 좌측 메뉴 불량 등록 클릭
  2. 날짜 · 담당자 · 제품명 입력 (제품명은 드롭다운, 없으면 "기타"로 추가)
  3. 컨테이너 번호 · 입고일자 · 구분(B2C/B2B) 입력
  4. 불량 유형 · 심각도 · 클레임 접수 경로 선택
  5. 불량 내용 상세 기재 후 사진 첨부 (여러 장 가능 · 자동 압축)
  6. 저장 클릭 → 전 직원 화면에 실시간 반영
📂 컨테이너별 보기
전체 기록 → 컨테이너별 보기 탭에서 컨테이너 번호별 폴더로 확인할 수 있습니다. 카드를 클릭하면 해당 컨테이너 기록만 필터링됩니다.
✅ 조치 상태 관리 NEW
불량을 기록하는 데서 끝나지 않고, 처리 진행 상황을 추적할 수 있습니다.
  • 미확인 → 확인 → 조치중 → 완료 (또는 보류)
  • 전체 기록 표에서 드롭다운으로 바로 변경 가능
  • 상세 화면에서 조치 내역(코멘트)을 남길 수 있으며 변경 이력이 자동 기록됩니다
  • 대응 기한 초과 시 ⏱ 기한초과 표시 — 긴급 24시간 · 중요 72시간 · 일반 7일 기준
  • 필터에서 미처리만 / 기한초과만 으로 빠르게 확인
⚡ 인사이트 탭
인사이트는 "무엇을 먼저 해야 하는가", 리포트는 "무슨 일이 있었나"를 봅니다.
