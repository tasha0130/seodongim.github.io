📁2. 준비할 파일

CSV와 엑셀(.xlsx, .xls) 모두 그대로 업로드할 수 있습니다. 한글이 깨진 CSV(EUC-KR)도 자동 인식하며, 엑셀 날짜 셀과 숫자로 저장된 SKU ID도 자동 변환됩니다. 파일의 첫 번째 시트만 읽습니다. PDF도 업로드할 수 있으며, 표의 칸 간격을 기준으로 열을 자동 인식합니다 (단, 스캔 이미지 PDF나 칸 구분이 불명확한 PDF는 정확도가 떨어질 수 있으니 가능하면 엑셀 원본을 권장합니다).

파일어디서 받나필수 컬럼 (자동 인식)
① 발주 파일쿠팡 서플라이어 허브 발주 목록 또는 발주서 업로드 양식발주번호, SKU ID(상품번호), SKU 이름, 물류센터, 입고예정일, 발주수량
② WMS 재고 파일3PL WMS 재고 다운로드SKU 컬럼(상품코드/품번/SKU) + 재고 컬럼(가용재고/현재고/재고수량)
③ 컨테이너 파일직접 작성 또는 입고 예정 자료차수(선택), SKU(품번코드·SKU ID·바코드), 수량, 도착예정일
④ 송장 파일물류센터(파트장님) 전달연번, 운송장번호, 전표번호(발주번호), 수령자(센터명)
  • 입고예정일이 오늘보다 이전인 발주는 업로드 시 자동 제외됩니다.
  • 재고 파일에 브랜드명 컬럼이 있으면 B2B 표기 행만 집계하고 B2C 재고는 자동 제외해, B2B/B2C 재고 분리 규칙이 지켜집니다.
  • 발주서 업로드 양식(.xlsx)을 그대로 STEP 1에 올리면, STEP 3에서 원본 서식·드롭다운이 유지된 양식을 받을 수 있습니다.
📝3. 단계별 사용 방법

STEP 1. 기본정보 & 파일 업로드

  • 발주 파일 업로드 칸을 클릭하거나 파일을 끌어다 놓습니다. 로드되면 "N개 발주 로드됨 | N개 입고예정일" 메시지가 뜹니다.
  • 입고예정일 목록에서 이번에 작업할 날짜를 클릭해 선택합니다(여러 개 선택 가능).
  • WMS 재고 파일을 업로드합니다. 성공하면 인식된 컬럼명이 알림으로 표시됩니다.
  • 재고 반영 조건 — 업로드하면 파일 안에서 등급·상태·브랜드처럼 값 종류가 적은 컬럼을 자동으로 찾아 체크박스로 보여줍니다. 체크한 값의 행만 재고로 집계되며, 기본값은 A로 시작하는 등급 + B2B 브랜드만 선택된 상태입니다. 물류사가 바뀌어 컬럼명이 「등급」이든 「상품상태」든, 값이 「양품」이든 「정상」이든 화면에서 골라주기만 하면 되고 코드 수정은 필요 없습니다. 선택은 이 브라우저에 저장되어 같은 형식의 파일을 다시 올리면 그대로 적용됩니다.
  • 매핑 결과 표에 발주 SKU마다 자동 조회된 품번코드(상품코드)가 함께 표시됩니다. "미등록"이면 설정에 없는 신규 SKU입니다.
  • 「기본 박스 입수 / 기본 풀파레트 수량」은 설정에 등록되지 않은 SKU에만 쓰이는 예비값(8 / 110)입니다. 등록된 62개 SKU는 상품별 값이 자동 적용되므로 보통 건드릴 필요가 없습니다.
※
상품별 박스입수·풀팔레트 수량 62개(설정 Config 시트 기준)와 센터 배송처코드 94개가 파일 안에 내장되어 있습니다. 스프레드시트의 설정 값이 바뀌면 대시보드도 업데이트가 필요합니다.

STEP 2. 출고일 및 컨테이너 설정

  • 출고일 관리: STEP 1에서 선택한 날짜가 자동 표시됩니다. 「+ 날짜 추가」로 다른 날짜를 더할 수 있습니다.
  • 컨테이너 파일 업로드: 중국 공장 FRC(최종출고확인서) 엑셀을 그대로 올리면 됩니다. 실제 장착 카톤 수 × 박스입수로 세트 수량을 자동 환산하고(150카톤 × 11 = 1,650세트), JS-H03 같은 공장 코드도 품번코드(JINSIM-10P00003)로 자동 변환합니다. 파일명의 숫자를 차수로 인식합니다.
  • FRC에는 도착예정일이 없으므로, 업로드 후 「차수별 도착예정일 일괄 지정」에서 날짜를 한 번에 넣거나 목록에서 개별 수정하세요.
  • 직접 추가 시 SKU는 드롭다운에서 고르면 되어 오타 걱정이 없습니다.
  • 실제 입고 후 수량이 달라지면 목록의 입고수량 칸에서 바로 수정할 수 있습니다. 잘못된 행은 「제거」, 빠진 건은 아래 「직접 추가」로 입력합니다.
  • 입력칸에서 Enter를 누르면 바로 등록되고 커서가 SKU 칸으로 돌아가 연속 입력이 편합니다.
  • 기타 출고 예정: N배송 등 쿠팡 외 채널로 나갈 물량을 등록하면 해당 날짜 이후 가용재고에서 자동 차감됩니다.
  • 지난 출고 확정 이력: STEP 3에서 확정하면 자동으로 쌓여 다음 출고일 계산에 반영됩니다. 이 PC 브라우저에 저장되어 창을 닫아도 유지되며, 잘못된 건은 삭제할 수 있습니다.
  • 이력이 지워졌다면 이전에 만든 WMS 출고 파일을 업로드해 복원할 수 있습니다. 고객사차수의 "(12일 출고)"와 주문일자를 조합해 출고일을 되살립니다.

STEP 3. 발주 확정 및 재고 조정

  • 가용재고는 날짜순 누적(원장) 방식으로 계산됩니다. 「직전 잔여 + 기간 내 컨테이너 입고 − 기타 출고 − 선행 출고」가 이번 출고일의 가용재고입니다. 가용재고 숫자에 마우스를 올리면 계산 근거가 표시됩니다.
  • 예를 들어 8/11에 컨테이너가 들어오고 8/12 출고가 먼저 나갔다면, 8/19 작업 시 8/12에 나간 물량이 자동으로 차감된 잔여만 쓸 수 있습니다.
  • 확정수량은 가용재고와 발주수량 중 작은 값으로 자동 채워지며, 고치면 이후 날짜 잔여까지 즉시 다시 계산됩니다.
  • 발주 중단 SKU는 「제외」 버튼으로 빼면 됩니다. 제외한 건은 발주서 양식에 확정수량 0 + 납품부족사유 "쿠팡 요청 미납"으로 기입되고, 박스·트럭 계산과 WMS·쉽먼트 파일에서도 빠집니다. 「되돌리기」로 복구할 수 있습니다.
  • 재고가 부족한 발주는 상태에 조정됨으로 표시됩니다.
  • 「발주서 업로드 양식 다운로드」: 쿠팡 원본 양식이 대시보드에 내장되어 있어, 어떤 형식의 발주 파일을 올렸든 색상·행 높이·열 너비·드롭다운이 원본 그대로인 양식에 값만 채워져 생성됩니다. 확정수량이 발주수량보다 적으면 납품부족사유가 자동 기입되고, 전량 확정이면 비워집니다.
※
현재고가 "-"로 표시되면 해당 SKU의 재고를 찾지 못한 것입니다. 이 경우 확정수량이 발주수량 기준으로 채워지므로 반드시 실제 재고를 확인 후 조정하세요.

STEP 4. 출고 유형 확정

  • 같은 입고예정일 + 같은 물류센터의 박스 수를 전부 합산해서, 합산 9박스 이하면 택배 📦, 초과하면 전체 화물 🚛로 자동 분류합니다.
  • 그래서 개별로는 소량(예: 2박스)인 SKU도 같은 센터·일자에 다른 SKU와 합쳐 9박스를 넘으면 "센터 합산 N박스 → 화물 통합"으로 표시됩니다. 물류비 절감을 위한 묶음이며 발주번호는 절대 변경되지 않습니다.
  • 화물 건은 SKU별 풀팔레트 수량 기준으로 필요한 팔레트 수가 표시됩니다.
  • 표 아래 「트럭 예약 요약」에서 발주번호·센터별 총 팔레트와 필요 트럭 대수(총 팔레트 ÷ 차량적재팔레트 16, 올림)를 확인할 수 있습니다.
  • 특수한 경우 각 행 오른쪽 선택칸에서 택배/화물을 수동 지정할 수 있습니다.
🚚
실제 출고 처리 순서는 반드시 택배 먼저, 그 다음 트럭입니다. 트럭 예약은 13:00~18:00 사이에만 가능합니다.

STEP 5. 쉽먼트 & 서류 생성

① WMS 출고 파일

  • 버튼을 누르면 STEP 3 확정수량 기준으로 WMS 업로드용 출고예정수신(B2B전용) 파일이 만들어집니다. 원본 양식이 내장되어 있어 색상·행 높이·테두리·열 너비가 양식과 완전히 동일하며, 남는 빈 양식 행도 그대로 유지됩니다.
  • 주문번호=발주번호, 수령자명=센터명, 수신상품코드=품번코드, 예정수량=확정수량, 배송처코드=내장 센터코드가 자동 기입됩니다.
  • 고객사차수는 "쿠팡 화물출고/택배출고 (N일 출고)" 형식이며, 택배 출고 행은 고객사차수·운송사코드(1010)가 빨간색으로 표기됩니다. 화물 행의 운송사코드는 비워집니다.
※
주문일자는 파일을 생성한 날짜(오늘)로 기입됩니다. 품번코드 미등록 SKU나 배송처코드가 없는 센터가 있으면 경고 메시지로 알려주니, 확인 후 엑셀에서 직접 수정하세요.

② 택배 쉽먼트 — 송장 입력

  • 물류센터에서 받은 송장 파일을 업로드하면, 센터·발주번호별로 필요한 송장 수(박스 수)와 파일의 송장 개수를 비교한 매칭 검증표가 표시됩니다.
  • 「쉽먼트 일괄 등록 파일 다운로드」를 누르면 ShipmentsUpload_PARCEL 양식(상품목록·송장번호입력·입력방법 3개 시트)이 작성됩니다. 박스입수를 초과하는 수량은 자동으로 행이 나뉘고(예: 88개·박스입수 11 → 11개씩 8행), 각 행에 송장번호가 순서대로 배정됩니다.
  • 매칭이 "불일치"인 발주는 송장번호가 빈칸으로 생성되므로, 파트장님께 확인 후 재업로드하거나 엑셀에서 직접 채워 넣으세요.
  • 택배 라벨·내역서 다운로드는 기존 PAD 자동화를 그대로 사용합니다.

③ 트럭 쉽먼트

  • 트럭(화물) 쉽먼트는 택배 처리 완료 후 서플라이어 허브에서 진행하며, 트럭 예약은 13:00~18:00에만 가능합니다. 적재리스트 등 서류는 PAD 자동화를 사용합니다.

재고 부족 조정 (마이너스 재고 & PO 매칭)

발주수량이 가용재고보다 많아 재고가 마이너스가 되는 SKU를 자동으로 찾아, 다른 센터의 발주(PO)를 이 센터로 돌려 부족분을 채우도록 추천하는 화면입니다.

  • 자동 감지: STEP 1~3을 진행하면 사이드바 「재고 부족 조정」 탭에서 마이너스 SKU와 필요 입고수량이 자동 표시됩니다.
  • PO 추천: SKU별 「추천 PO 보기」를 누르면 부족분을 채울 수 있는 발주가 순위대로 나옵니다. 1순위는 여러 부족 SKU를 한 번에 해결하거나 부족분을 가장 많이 채우는 발주입니다.
  • 센터 제외: XRC 계열처럼 변경 불가한 센터는 체크해서 추천에서 뺄 수 있습니다.
  • 변경 요청서: 추천 발주를 체크해 「변경 요청 목록에 추가」하고, 변경할 센터를 입력한 뒤 엑셀로 내보내면 쿠팡 제출용 납품센터 변경 요청서가 됩니다.
💡
이 추천은 통계가 아니라 실제 발주 데이터를 검색한 결과입니다. STEP 1에 올린 발주 파일 안의 모든 센터·발주를 대상으로 찾습니다.
📚4. 기준정보 탭 (구글시트 대체)

탭 메뉴의 「기준정보」를 누르면 구글시트를 열지 않고도 아래 4가지 자료를 바로 조회할 수 있습니다. 각 자료는 서브탭으로 구분되며, 검색창에 아무 단어나 입력하면 즉시 걸러지고 엑셀 다운로드도 가능합니다(검색 결과만 받는 것도 됩니다).

  • 설정(Config) — SKU ID ↔ 바코드 ↔ 품번코드 매핑과 박스입수·PLT당수량. 대시보드의 박스 환산·택배/화물 분류가 이 값을 사용합니다.
  • 쿠팡 제품 정보 — 쿠팡 B2B 등록 상품명과 F_PLT 기준·1BOX 총수량. 화물 출고 시 F_PLT 기준 수량을 확인하는 용도입니다.
  • B2B 납품 센터 주소 — 센터명 ↔ 배송처코드 ↔ 주소. STEP 5 WMS 파일의 배송처코드가 여기서 조회됩니다.
  • 일자별 재고잔여(SKU별) — 현재재고 + 컨테이너 입고예정 − 출고 계획으로 계산된 일자별 잔여. 음수는 빨간색으로 표시되어 재고 부족 일자를 바로 찾을 수 있습니다.

직접 등록·수정하기

  • 수정 / 삭제 — 각 행 오른쪽 버튼으로 값을 고치거나 행을 지웁니다. 수정 중에는 행이 입력칸으로 바뀌며, 「저장」 또는 「취소」를 누르면 됩니다.
  • ＋ 행 추가 — 신규 SKU나 새 센터를 등록합니다. 빈 행이 맨 위에 생기고 바로 입력 상태가 됩니다.
  • 엑셀로 교체 — 구글시트에서 대량 갱신했다면 파일을 올려 표 전체를 한 번에 덮어씁니다(교체 전 확인 창이 뜹니다).
  • 열 너비 조절 — 표 제목줄에서 열과 열 사이 경계에 마우스를 대면 커서가 ↔ 모양으로 바뀝니다. 그대로 좌우로 끌면 너비가 조절되어, 상품명처럼 긴 값을 넓게 펼쳐 볼 수 있습니다. 「↔ 너비 초기화」로 기본값 복원.
  • 설정(Config)·센터 주소를 고치면 계산에 즉시 반영됩니다. 박스입수를 바꾸면 STEP 3~4의 박스 환산과 택배/화물 분류가, 배송처코드를 바꾸면 STEP 5의 WMS 파일이 새 값을 씁니다.
🔄
수정 내용은 현재 창에서만 유지됩니다. 새로고침하거나 브라우저를 닫으면 원래 값으로 돌아가니, 고친 자료는 「엑셀 다운로드」로 받아 두시고 구글시트에도 반영해 주세요. Firebase 연동이 확정되면 자동 저장되고 모든 PC에 공유되도록 전환할 예정입니다.

🔧6. 문제 해결 (FAQ)
증상원인과 해결
현재고가 "-" / 재고 미확인해당 SKU가 재고 파일에 없거나 설정 62개에 등록되지 않은 신규 SKU입니다. 재고 파일에 상품이 있는지 확인하고, 신규 상품이면 설정 시트에 추가 후 대시보드 업데이트가 필요합니다.
"컬럼을 찾지 못했습니다" 알림파일의 컬럼 이름이 예상과 다릅니다. 알림에 표시된 파일 헤더를 확인하세요. 헤더가 첫 행이 아닌 파일은 첫 행에 컬럼명이 오도록 정리 후 다시 업로드합니다.
"⚠ 미등록 SKU" 표시설정에 없는 SKU라 기본 박스입수/풀파레트 값이 적용된 상태입니다. 값이 맞는지 확인하고, 계속 나오는 상품이면 설정 시트에 등록하세요.
"오늘 이후 발주가 없습니다"파일의 입고예정일이 모두 과거 날짜입니다. 최신 발주 파일인지 확인하세요.
